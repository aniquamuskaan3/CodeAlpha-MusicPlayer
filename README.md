🎵 Music Player

A modern and responsive Music Player built using HTML, CSS, and JavaScript. The application allows users to play music, manage playlists, upload local audio files, control playback, adjust volume, and enjoy animated visual effects while listening to their favorite songs.

✨ Features
▶️ Play & Pause Music
⏮ Previous and ⏭ Next Track Controls
📃 Interactive Playlist
🎵 Upload and Play Local Audio Files
📊 Animated Audio Visualizer
⏩ Seek Bar for Track Navigation
🔊 Volume Control
🎨 Dynamic Animated Background Effects
✨ Modern Glassmorphism User Interface
⌨️ Keyboard Shortcuts Support
Space → Play/Pause
Left Arrow → Previous Song
Right Arrow → Next Song
🔄 Automatic Next Song Playback
📱 Responsive Design
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
HTML Audio API
Canvas API
🎯 Project Objective

The objective of this project is to create an interactive web-based music player that provides a smooth audio experience while demonstrating modern frontend development concepts such as audio handling, DOM manipulation, event management, and responsive user interface design.
